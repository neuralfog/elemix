# Installation

Bootstrap a new ***elemix*** app with the scaffold. One command, and you have a
project wired up and ready to run.

```sh
npm create elemix-app
```

```sh
pnpm create elemix-app
```

```sh
npx create-elemix-app my-app
```

No magic under the hood - the scaffold just clones
[elemix-template](https://github.com/neuralfog/elemix-template). Prefer to start
from the template directly? Clone it yourself.
