# Editor Support

***elemix*** ships first-class editor support for VS Code and Neovim, both with
full LSP support.

- [Neovim](https://github.com/neuralfog/elemix.nvim)
- [VS Code](https://marketplace.visualstudio.com/items?itemName=neuralfog.elemix)

Both depend on two packages in your project. Install them as dev dependencies:

```sh
pnpm add -D @neuralfog/elemix-analyzer @neuralfog/elemix-template-formatter
```

See [elemix-template](https://github.com/neuralfog/elemix-template) for a full,
working setup.
